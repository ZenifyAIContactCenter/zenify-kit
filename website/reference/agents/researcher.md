# Agent `researcher`

Worker research web với hợp đồng output cố định — mỗi phát hiện là một quote nguyên văn từ URL đã fetch, hoặc ghi rõ không tìm thấy; có mode verify fetch lại URL của worker khác.

Agent trả lời đúng một câu hỏi con trong giới hạn số lần gọi tool mà lead đặt, ghi toàn bộ vào file lead chỉ định và chỉ trả về tối đa 40 dòng. Mỗi phát hiện theo dạng "According to URL: quote nguyên văn → claim"; điều không tìm được ghi "not found" kèm đã thử ở đâu. Agent không có tool `Agent` nên không tự phân nhánh, không có `Bash` nên không chạy lệnh trong repo.

## Hai mode

- **research** (mặc định, sonnet): tìm rộng rồi thu hẹp, ưu tiên nguồn chính thức, dừng khi đạt tiêu chí hoặc hết cap.
- **verify** (lead dispatch với model haiku): đọc file của các worker, fetch lại từng URL, so quote với trang, ghi `verify.md` với trạng thái `VERIFIED` / `QUOTE-MISMATCH` / `DEAD-URL` / `NOT-FETCHED`. Không sửa file worker.

## Khi nào được gọi

`/znf:research` dispatch agent này ở bước 2 (worker) và bước 3 (verifier). Skill khác cần một phát hiện có nguồn kiểm chứng cũng dispatch trực tiếp với cùng hợp đồng.

## Lưu ý

Fetch lỗi (403, timeout, paywall) ghi vào "not found" kèm URL, không thay bằng trí nhớ về trang đó. Agent không đọc repo của caller để trả lời câu hỏi web.
