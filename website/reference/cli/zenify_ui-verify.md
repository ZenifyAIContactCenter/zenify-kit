# `zenify ui-verify`

Nhóm lệnh ghi/kiểm tra bằng chứng UI-verify cho gate cơ học của /znf:ship.

## Cú pháp

```text
zenify ui-verify
```

## Tổng quan

Gồm `record` (agent `ui-verifier` ghi lại screenshot + số đo layout keyed theo fingerprint hiện tại) và `check` (`/znf:ship` bước 7 dùng để gate fail-closed trước khi kết luận Shippable). Xem [Kiểm thử UI](/workflows/ui-testing).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify ui-verify check](./zenify_ui-verify_check): Gate fail-closed kiểm tra artifact UI-verify còn khớp fingerprint hiện tại.
- [zenify ui-verify record](./zenify_ui-verify_record): Ghi lại artifact UI-verify (screenshot + 3 số đo) cho fingerprint hiện tại.
