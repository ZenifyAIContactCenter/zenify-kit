## zenify db-perf

Quét tĩnh một diff tìm anti-pattern query (hai tầng) — advisory, fail-open

```
zenify db-perf [flags]
```

### Options

```
      --diff-file string   read a unified diff from this file instead of git
      --from string        base ref for the diff (default "origin/staging")
  -h, --help               help for db-perf
      --json               emit the machine-readable Result JSON
      --to string          head ref for the diff (default "HEAD")
```
