# `zenify doctor`

Kiểm tra sức khỏe môi trường ZenifyKit trên máy và báo từng mục đạt hay hỏng.

## Cú pháp

```text
zenify doctor [flags]
```

## Khi nào dùng

Ngay sau `zenify up`, và mỗi khi một skill báo thiếu tool, thiếu secret hoặc Playwright không chạy. Lệnh chỉ đọc, chạy bao nhiêu lần cũng được.

## Kết quả

Mỗi dòng là một mục kiểm tra kèm dấu đạt hoặc hỏng và chi tiết. Các mục gồm phiên bản binary, đăng nhập git và quyền truy cập GitHub, danh tính commit của git (`user.name`, `user.email`), credential trong `.zenify/.env` (`secrets`, `env-file`, `settings-env`), tool bên ngoài (`git`, `gh`, `mongosh`, `mysql`), Playwright, Docker, hook `git-guard` trong `<workspace>/.claude/settings.local.json`, plugin skill `znf` (bật ở workspace, còn thư mục plugin trong marketplace), luật `permissions` của kit ở workspace, hook Codex trong `<workspace>/.codex` (`codex-hooks`), engine review (`reviewer`) và file `AGENTS.md` của từng repo (`agents-md`), rule cá nhân trong `~/.claude/rules` trùng tên với rule của workspace (`shadow`; skill và agent không còn xét vì skill của plugin luôn mang tiền tố `znf:`), dung lượng file hướng dẫn luôn nạp (`context-budget`), entry ngoài quy ước ở root và `docs/` (`workspace-root`) và MEMORY.md gần trần (`memory-index`). Mục hỏng in luôn chi tiết để bạn sửa. Mục `git-guard` hỏng thì `--fix` tự gắn lại hook. Khi kit còn cài ở cấp user (máy chưa chạy `zenify up --apply` bản cài theo workspace), mục `git-guard` và `kit-permissions` đạt kèm lời nhắc chạy `zenify up --apply`, và `--fix` không ghi gì vào workspace để hook không chạy hai lần. `--fix` của `kit-permissions` không thêm lại luật kit bạn đã xoá ở `~/.claude/settings.json`. Mục `npm token (GitHub Packages)` chỉ áp dụng khi một repo cài package từ GitHub Packages: nó xét account github.com đang active của `gh`, báo thiếu scope `read:packages` hoặc `NPM_TOKEN` chưa tới shell mới, và báo `gh auth status timed out` nếu `gh` không trả lời sau 10 giây. Mục này hỏng thì `--fix` chạy cùng logic với `zenify npm login`: trong terminal nó có thể chạy `gh auth refresh -h github.com -s read:packages` (mở trình duyệt hoặc device flow) rồi thêm dòng vào profile shell; không có TTY thì chỉ in lệnh đó.

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--exit-on-fail` | Trả mã thoát khác 0 khi có mục hỏng. Dùng trong script và CI. |
| `--fix` | Tự sửa các mục an toàn rồi kiểm tra lại. Những mục cần bạn tự làm vẫn in hướng dẫn. |
| `--json` | In kết quả dạng JSON. |

## Ví dụ

```bash
zenify doctor
zenify doctor --fix
```

## Lưu ý

Credential được đọc từ `.zenify/.env` ở workspace, nên phải mở session từ trong workspace. Xem [Bắt đầu nhanh](/getting-started/quickstart) để biết từng mục nghĩa gì.
