## zenify visual check

So từng route với baseline; --update để chụp lại baseline

```
zenify visual check [flags]
```

### Options

```
  -h, --help          help for check
      --port int      port dev-server trên host
      --repo string   target repo path (mặc định cwd)
      --update        chụp lại baseline thay vì so
```
