## zenify wt new

Tạo worktree: branch + port + env đã seed + deps

```
zenify wt new <slug> [flags]
```

### Options

```
      --another       allow a second concurrent task in this repo
      --base string   override the base ref (e.g. this week's release)
  -h, --help          help for new
      --install       force deps=install even if config says symlink/clone
      --type string   feat|fix|chore|hotfix (default "feat")
```
