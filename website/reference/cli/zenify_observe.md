# `zenify observe`

Nhóm lệnh theo dõi phiên Claude Code: số lần dispatch subagent và lượng tool output.

## Cú pháp

```text
zenify observe
```

## Tổng quan

Hai hook của kit ghi lại số lần dispatch subagent và lượng tool output theo phiên. Nhóm lệnh này đọc dữ liệu đó thành báo cáo hoặc một dòng statusline trong Claude Code. Xem [Hook](/reference/hooks).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify observe report](./zenify_observe_report): Tóm tắt số lần dispatch subagent và lượng tool output của từng phiên Claude Code.
- [zenify observe statusline](./zenify_observe_statusline): Vẽ một dòng statusline cho Claude Code với model, ngữ cảnh, số dispatch, tool output và chi phí.
