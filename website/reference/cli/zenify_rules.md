# `zenify rules`

Nhóm lệnh kiểm tra rule team, hiện có lệnh lint ngôn ngữ cho file agent đọc.

## Cú pháp

```text
zenify rules
```

## Tổng quan

Rule team phân phối tới mọi máy phải viết bằng tiếng Anh để agent đọc ổn định. Lệnh con `lint` kiểm tra điều đó. Skill và rule đọc bởi agent xem [Ba lớp](/concepts/three-layers).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify rules lint](./zenify_rules_lint): Chặn tiếng Việt trong file mà agent đọc: skill, rule, và mã nguồn kit.
