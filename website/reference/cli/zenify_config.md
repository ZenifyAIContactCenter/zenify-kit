## zenify config

phân phối config workspace-level từ docs/.config (dry-run mặc định)

```
zenify config [flags]
```

### Options

```
      --apply               ghi thay đổi (mặc định chỉ dry-run)
      --config-dir string   thư mục config nguồn (mặc định repo docs/.config, tự tìm theo layout)
  -h, --help                help for config
      --workspace string    thư mục workspace (mặc định: tự tìm, không có thì cwd)
```
