## zenify wt rm

Gỡ một worktree (từ chối worktree dirty/detached/chưa merge nếu không có --force)

```
zenify wt rm <slug> [flags]
```

### Options

```
  -f, --force   remove even if dirty, detached, or unmerged
  -h, --help    help for rm
```
