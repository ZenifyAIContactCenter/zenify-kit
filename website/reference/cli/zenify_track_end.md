# `zenify track end`

Đóng một lượt theo dõi với PR, branch, rollback hoặc cancelled; đếm số task từ ledger SDD và lưu đường dẫn plan từ dòng đầu.

## Cú pháp

```text
zenify track end <id> (--pr <url>... | --branch <name> | --rollback | --cancelled | --done) [--ledger <path>] --rounds N [flags]
```

## Khi nào dùng

Sau khi `znf:ship` mở PR, hoặc ở step 10 của hotfix. Id chưa start hoặc đã end thì lệnh báo lỗi và không ghi.

## Kết quả

Ghi dòng `end` vào sổ rồi in `track: ended <id>`. Hook của plugin `znf` chỉ gỡ id khỏi session khi thấy dòng này, nên một lệnh end bị từ chối không làm mất phần đo của việc vẫn đang mở.

## Ví dụ

```bash
zenify track end fix-261030-ab12 --pr https://github.com/org/repo/pull/1 --ledger progress.md --rounds 1
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--branch` | pushed branch name (hotfix; the human opens the PR) |
| `--cancelled` | the run was cancelled |
| `--done` | the work is finished with no PR (ops work) |
| `--ledger` | SDD ledger file; its `Task \<N\>: complete` lines are counted and its first-line plan path is kept |
| `--pr` | pull request URL (repeatable) |
| `--rollback` | the run ended in a rollback |
| `--rounds` | fix rounds of the review in znf:ship |
