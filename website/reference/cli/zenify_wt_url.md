# `zenify wt url`

In địa chỉ http://localhost:\<port\> của dev server thuộc một slug.

## Cú pháp

```text
zenify wt url <slug>
```

## Khi nào dùng

Khi cần mở app của một worktree trên trình duyệt, hoặc đưa URL cho bước verify UI.

## Kết quả

Lệnh in đúng một dòng dạng `http://localhost:<port>`, lấy port đã cấp cho worktree đó.

## Ví dụ

```bash
zenify wt url session-timeout
```
