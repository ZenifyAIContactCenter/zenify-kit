# `zenify track stats`

In số liệu hôm nay, độ chính xác estimate và chất lượng từ log.md và sessions/*.log.

## Cú pháp

```text
zenify track stats [flags]
```

## Khi nào dùng

Pane gọi lệnh này với `--json`. Feature tắt thì in `enabled: false` và không đọc log.

## Ví dụ

```bash
zenify track stats --json
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--brief` | output compact JSON for agents: carried, daily plan, open PRs, backlog (no timing, tokens or quality) |
| `--dir` | directory holding log.md (default: \<workspace\>/.zenify/track) |
| `--force` | ignore the 5-minute backlog cache (gh issues and SDD scan) |
| `--json` | output JSON instead of a short summary |
| `--today` | the day to report, YYYY-MM-DD (default: local today) |
