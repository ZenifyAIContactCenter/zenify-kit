# `zenify spec`

Nhóm lệnh soi vòng đời spec và registry contract, đọc từ knowledge store.

## Cú pháp

```text
zenify spec
```

## Tổng quan

Spec nằm trong knowledge store. Hai lệnh con suy ra trạng thái của từng spec từ plan và lịch sử git, và gom các tag rủi ro thành registry contract. Xem [Knowledge store](/concepts/knowledge-store).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify spec contracts](./zenify_spec_contracts): Liệt kê repo và collection mà từng spec khai qua hai tag `_Blast-radius:` và `_DB:`.
- [zenify spec status](./zenify_spec_status): Liệt kê trạng thái vòng đời của từng spec trong knowledge store.
