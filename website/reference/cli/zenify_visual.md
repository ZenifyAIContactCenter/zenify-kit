# `zenify visual`

Nhóm lệnh visual regression: chụp từng route và so với ảnh baseline đã commit.

## Cú pháp

```text
zenify visual
```

## Tổng quan

Playwright chạy trong Docker với phiên bản đã ghim, nên ảnh baseline dùng được trên mọi máy. Danh mục route nằm ở `.znf/visual/routes.json` của repo. Cách dùng trong bước verify xem [Kiểm thử UI](/workflows/ui-testing).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify visual check](./zenify_visual_check): So ảnh chụp từng route với baseline, hoặc chụp lại baseline khi giao diện đổi có chủ ý.
