# `zenify obs`

Tóm tắt sức khỏe một route hoặc một trace qua broker, đã che PII và giới hạn kích thước.

## Cú pháp

```text
zenify obs [id] [flags]
```

## Khi nào dùng

Khi cần trả lời nhanh "route này đang chậm hay lỗi?" hoặc "trace này đi qua đâu, hỏng ở đâu?" mà chưa muốn tự viết truy vấn Tempo và Loki. Broker gọi Grafana thay bạn, gộp kết quả, che PII và cắt về kích thước nhỏ. Cần chi tiết hơn thì mới dùng các tool Grafana trực tiếp.

## Kết quả

Hai chế độ, chọn đúng một:

- `zenify obs <id> --route "<METHOD path>"`: thống kê route của service `<id>` trong khoảng `--since` (số lượng, tốc độ, p50/p95/p99, tỉ lệ lỗi, phân bố status), vài trace chậm nhất và trace lỗi làm mẫu, và số dòng log lỗi của service.
- `zenify obs --trace <trace-id>`: tóm tắt một trace (span gốc, các service, nhóm span, span lỗi) cùng các dòng log nhắc tới trace id.

Mặc định in YAML gọn; `--json` in JSON của response. Khi broker phải cắt bớt, lệnh ghi một dòng `obs: response truncated (<loại>=<số>, …)` ra stderr; stdout vẫn chỉ chứa kết quả.

Mã thoát:

| Mã | Ý nghĩa |
|---|---|
| 0 | Thành công |
| 2 | Sai tham số: không chọn đúng một trong `--route`/`--trace`, không chọn đúng một trong `--prd`/`--stg`, `--route` thiếu `<id>`, hoặc broker từ chối đầu vào (service lạ, `--since` sai, trace id sai) |
| 5 | Broker không bật `obs`: manifest không khai báo `broker:` hoặc broker trả 404 |
| 1 | Không tìm thấy trace, hoặc lỗi khác |

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--route` | Route cần tóm tắt, dạng `"<METHOD path>"`. Cần thêm `<id>` service. Không dùng chung với `--trace`. |
| `--trace` | Trace id (1 đến 32 ký tự hex). Không dùng chung với `--route`. |
| `--since` | Khoảng nhìn lại cho `--route`, dạng Go duration. Mặc định `24h`, tối đa `48h`. |
| `--prd` | Dữ liệu production. Phải có đúng một trong `--prd`/`--stg`. |
| `--stg` | Dữ liệu staging. |
| `--json` | In JSON của response thay cho YAML. |
| `--manifest` | File manifest có `broker:` quyết định broker. Mặc định là manifest nhúng sẵn trong binary. |
| `--overlay` | File overlay cá nhân. Overlay không đổi `broker:`. |

## Ví dụ

```bash
zenify obs svc-a --route "GET /items" --prd
zenify obs svc-a --route "POST /items" --stg --since 6h
zenify obs --trace 4bf92f3577b34da6a3ce929d0e0e4736 --prd --json
```
