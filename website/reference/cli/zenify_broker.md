# `zenify broker`

Nhóm lệnh làm việc với credential broker của zenify.

## Cú pháp

```text
zenify broker
```

## Khi nào dùng

Khi manifest của team khai báo `broker:`. Hiện có hai lệnh con là `zenify broker token` và `zenify broker headers`; các lệnh khác của kit dùng broker qua cùng cache token này.

## Kết quả

Manifest không khai báo `broker:` thì mọi lệnh kit giữ nguyên hành vi trước đây.

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify broker headers](./zenify_broker_headers): In header Authorization cho MCP http của Claude Code, dưới dạng một object JSON.
- [zenify broker token](./zenify_broker_token): In JWT của credential broker ra stdout, dùng cache và tự xin lại khi còn dưới 60 giây.
