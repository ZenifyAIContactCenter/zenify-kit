## zenify wt config

Hiện worktree.json đã resolve (hoặc --port \<key\> để xem port đã cấp)

```
zenify wt config [flags]
```

### Options

```
  -h, --help          help for config
      --port string   print the allocated port for this key instead of the full config
```
