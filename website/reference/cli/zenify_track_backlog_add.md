# `zenify track backlog add`

Thêm một việc thủ công vào backlog và in `track: <bid>`.

## Cú pháp

```text
zenify track backlog add "<title>" --repo <r> [--est S|M|L] [--ref <url|memory:<name>>] [flags]
```

## Khi nào dùng

Khi có việc cần làm sau; bid dạng `b-<YYMMDD>-<4 hex>`. `start --from <bid>` đưa việc ra khỏi backlog.

## Ví dụ

```bash
zenify track backlog add "gộp hai helper" --repo kit --est M --ref memory:foo
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--est` | size estimate S\|M\|L, or - when not known yet (mặc định `-`) |
| `--ref` | issue URL or memory:\<name\> (mặc định `-`) |
| `--repo` | target repo name |
