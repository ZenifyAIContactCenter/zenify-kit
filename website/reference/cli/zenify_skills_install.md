## zenify skills install

materialize coding skill (leg-1) cho repo hiện tại vào .claude/skills

```
zenify skills install [flags]
```

### Options

```
      --dest string   thư mục đích (mặc định: .claude/skills)
  -h, --help          help for install
      --repo string   tên repo (mặc định: basename cwd)
```
