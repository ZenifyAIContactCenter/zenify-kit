## zenify migrate

gom repo vào một thư mục con (dry-run mặc định; move-and-repair: gom được cả repo dirty và repo còn worktree)

```
zenify migrate [flags]
```

### Options

```
      --apply              thực hiện move (mặc định chỉ dry-run)
  -h, --help               help for migrate
      --to string          tên thư mục đích gom repo (default "repos")
      --workspace string   thư mục workspace (mặc định cwd)
```
