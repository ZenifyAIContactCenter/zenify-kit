# `zenify track onboard`

Nạp dữ liệu ban đầu cho track.

## Cú pháp

```text
zenify track onboard
```

## Khi nào dùng

Một lần cho mỗi dev mới bật feature track: `memory` đánh dấu đã đọc memory, `history` nạp lịch sử từ transcript.

## Ví dụ

```bash
zenify track onboard history
```
