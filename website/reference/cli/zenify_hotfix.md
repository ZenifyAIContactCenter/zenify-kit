# `zenify hotfix`

Nhóm lệnh hỗ trợ hotfix, hiện có một lệnh con in base ref đã resolve.

## Cú pháp

```text
zenify hotfix
```

## Tổng quan

Hotfix tạo branch từ release đang chạy, không từ branch tích hợp. Lệnh con `baseref` cho bạn biết `zenify wt new --type hotfix` sẽ dùng ref nào. Workflow đầy đủ xem [hotfix](/workflows/hotfix).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify hotfix baseref](./zenify_hotfix_baseref): In base ref mà hotfix của một repo sẽ xuất phát, theo chiến lược khai trong `worktree.json`.
