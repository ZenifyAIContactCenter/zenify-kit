## zenify wt ls

Liệt kê worktree trong repo này (git ⋈ state), kèm trạng thái running/merged

```
zenify wt ls [flags]
```

### Options

```
      --all    list every wt-managed repo in the workspace, grouped by repo
  -h, --help   help for ls
      --json   emit the rows as a JSON array (editor-agnostic)
```
