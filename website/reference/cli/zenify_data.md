# `zenify data`

Nhóm lệnh chạy script dữ liệu với credential DB do broker cấp, không để lộ giá trị trong output.

## Cú pháp

```text
zenify data
```

## Tổng quan

Script dữ liệu cần kết nối Mongo, MySQL, Redis hoặc lumi-agent. Lệnh `run` xin credential từ broker, chạy script của bạn với credential đó và che giá trị trong output. Credential không được ghi ra đĩa.

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify data run](./zenify_data_run): Chạy một lệnh với credential DB từ broker, che giá trị trong stdout và stderr, ghi thật phải dry-run trước.
