## zenify standards

Kiểm test-traceability — mỗi FR có một test thật trên đĩa (advisory, fail-open)

```
zenify standards [flags]
```

### Options

```
  -h, --help          help for standards
      --json          emit the machine-readable Result JSON
      --plan string   path to the plan markdown file
      --root string   directory test paths resolve against (default: current dir)
      --spec string   path to the spec markdown file
```
