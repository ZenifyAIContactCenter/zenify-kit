## zenify analyze

Phân tích cơ học cặp spec+plan (coverage, marker, cấu trúc Brief) — advisory, fail-open

```
zenify analyze [flags]
```

### Options

```
  -h, --help          help for analyze
      --json          emit the machine-readable Result JSON
      --plan string   path to the plan markdown file
      --spec string   path to the spec markdown file
```
