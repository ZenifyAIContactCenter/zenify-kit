# `zenify ui-verify style`

Lint màu và giá trị viết cứng trên các dòng mới thêm của nhánh, theo luật khai trong `uiVerify.style`.

## Cú pháp

```text
zenify ui-verify style [flags]
```

## Khi nào dùng

Chạy trước khi báo xong một thay đổi UI. Chỉ xét dòng `+` của file render (`.tsx`, `.jsx`, `.vue`, `.svelte`) so với merge-base, nên nợ cũ không bị tính. Ba luật: `hex` (màu `#fff`), `palette` (class màu thô như `bg-red-500`), `arbitrary` (giá trị như `w-[437px]`). Repo không khai `uiVerify.style` thì in `no style rules declared` và exit 0.

Có vi phạm thì in `<file>:<line> <luật> <chuỗi khớp>` và exit 1. Miễn một dòng bằng comment `znf:ui-style-ok: <lý do>` trên chính dòng đó hoặc dòng thêm ngay trước nó; marker `znf:ui-verify-ok:` không miễn lint này. `zenify ui-verify check` chạy luôn lint này.

## Ví dụ

```bash
zenify ui-verify style --repo . --base "$(zenify wt base)"
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--base` | base ref để so sánh (bắt buộc) |
| `--repo` | repo path (mặc định cwd) |
