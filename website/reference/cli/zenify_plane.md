# `zenify plane`

Nhóm lệnh làm việc với Plane bằng PAT của chính dev.

## Cú pháp

```text
zenify plane
```

## Khi nào dùng

Dùng khi cần tạo việc trên Plane ngay từ terminal hoặc từ `/znf:track add --plane`. URL và workspace Plane lấy từ manifest, PAT lấy từ `PLANE_API_KEY` trong môi trường hoặc `.zenify/.env`. Hiện có một lệnh con: `create`.

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify plane create](./zenify_plane_create): Tạo work item Plane giao cho chính bạn và in key kèm URL.
