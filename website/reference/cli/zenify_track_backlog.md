# `zenify track backlog`

Quản lý backlog thủ công của pane (thêm, bỏ).

## Cú pháp

```text
zenify track backlog
```

## Khi nào dùng

Dùng `add` và `drop`; tab Backlog của pane gom thêm issue GitHub và việc defer/parked trong ledger SDD.

## Ví dụ

```bash
zenify track backlog add "đổi tên helper" --repo kit --est S
```
