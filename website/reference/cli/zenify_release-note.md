## zenify release-note

ghi note-commit release (trailer risk-metadata) — dùng bởi /ship

```
zenify release-note [flags]
```

### Options

```
      --blast string      _Blast-radius (default 'unknown')
      --db string         _DB (default 'N/A')
      --dir string        repo dir (mặc định cwd)
  -h, --help              help for release-note
      --note string       mô tả một dòng
      --rollback string   _Rollback (default 'revert PR')
      --slug string       slug thay đổi (bắt buộc)
      --spec string       path spec (tuỳ chọn)
```
