# `zenify track ship`

Ghi kết quả một lần chạy znf:ship: shipped hay blocked, bước bị chặn, số finding và số vòng fix.

## Cú pháp

```text
zenify track ship <id> --outcome shipped|blocked [--blocked-step <step>] --findings C,H,M,L|- --rounds N [flags]
```

## Khi nào dùng

Cuối mỗi lần chạy `znf:ship` khi có id đang mở. `--blocked-step` bắt buộc khi blocked.

## Ví dụ

```bash
zenify track ship fix-261030-ab12 --outcome blocked --blocked-step lint --findings 0,1,2,0 --rounds 1
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--blocked-step` | lint\|build\|contract\|behaviour\|review (required when blocked) |
| `--findings` | C,H,M,L finding counts, or - (mặc định `-`) |
| `--outcome` | shipped\|blocked |
| `--rounds` | fix rounds the review took |
