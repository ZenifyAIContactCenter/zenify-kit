## zenify e2e run

Chạy journey .znf/e2e trong Docker (cần --port dev-server host)

```
zenify e2e run [flags]
```

### Options

```
  -h, --help          help for run
      --port int      port dev-server trên host
      --repo string   target repo path (mặc định cwd)
```
