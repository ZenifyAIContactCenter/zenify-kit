# `zenify track plan`

Quản lý kế hoạch trong ngày của pane (đặt danh sách việc).

## Cú pháp

```text
zenify track plan
```

## Khi nào dùng

Dùng `set` để chốt các việc định làm hôm nay; pane đối chiếu kế hoạch với những gì đã ship.

## Ví dụ

```bash
zenify track plan set b-261105-ab12 https://github.com/o/r/pull/3
```
