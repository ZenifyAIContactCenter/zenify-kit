# `zenify track onboard history`

Xem trước hoặc ghi lịch sử làm việc lấy từ transcript Claude Code.

## Cú pháp

```text
zenify track onboard history [--write] [--since YYYY-MM-DD] [flags]
```

## Khi nào dùng

Chạy không `--write` để xem trước; `--write` append mỗi nhóm (repo, slug) đúng một dòng `history`.

## Ví dụ

```bash
zenify track onboard history --since 2026-10-01
```

## Cờ

| Cờ | Ý nghĩa |
|---|---|
| `--since` | ignore records before this day, YYYY-MM-DD |
| `--write` | append the history rows (default: preview only) |
