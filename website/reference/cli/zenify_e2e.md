# `zenify e2e`

Nhóm lệnh cho journey E2E: lint chống test hời và chạy journey Playwright thật trong Docker.

## Cú pháp

```text
zenify e2e
```

## Tổng quan

Journey E2E nằm trong thư mục `.znf/e2e` của repo. Bạn dùng `lint` để chặn journey thiếu re-fetch, assert hoặc cleanup, và `run` để chạy journey trên dev server đang mở. Cách viết journey xem [Kiểm thử UI](/workflows/ui-testing).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify e2e lint](./zenify_e2e_lint): Kiểm tra cơ học các journey trong `.znf/e2e`, chặn journey thiếu re-fetch, assert hoặc cleanup.
- [zenify e2e run](./zenify_e2e_run): Chạy journey E2E trong Docker, trỏ vào dev server đang mở trên máy bạn.
