## zenify docs sync

đồng bộ docs: pull + commit + push (fail-open)

```
zenify docs sync [flags]
```

### Options

```
      --dir string         thư mục repo docs (mặc định tự tìm theo layout)
  -h, --help               help for sync
      --workspace string   thư mục workspace (mặc định: tự tìm, không có thì cwd)
```
