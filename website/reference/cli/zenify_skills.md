# `zenify skills`

Nhóm lệnh quản lý plugin skill znf và bộ coding skill theo repo.

## Cú pháp

```text
zenify skills
```

## Khi nào dùng

`skills sync` cập nhật bộ skill `znf:*` dùng chung cho mọi repo. `skills install` gỡ bản coding skill cũ khỏi repo bạn đang đứng (chúng đã nằm trong `znf`). `zenify up` chỉ gọi `skills sync`; `skills install` bạn gõ tay một lần trong mỗi repo còn bản cũ.

Xem [Namespace znf](/concepts/znf-namespace) và [Ba lớp của kit](/concepts/three-layers).

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify skills install](./zenify_skills_install): Gỡ bản coding skill cũ khỏi .claude/skills của repo — chúng đã nằm trong plugin znf.
- [zenify skills sync](./zenify_skills_sync): Ghi bộ skill znf từ binary vào ~/.claude/skills/znf và gắn hook znf vào settings.
