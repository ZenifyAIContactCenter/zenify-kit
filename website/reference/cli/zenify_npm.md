# `zenify npm`

Nhóm lệnh cấu hình npm cho package private trên GitHub Packages.

## Cú pháp

```text
zenify npm
```

## Khi nào dùng

`zenify up` tự đặt `NPM_TOKEN` khi workspace có repo cài package từ GitHub Packages. Nhóm này chỉ có `login` để chạy lại riêng phần đó, không cần chạy cả `zenify up`.

## Lệnh liên quan

- [zenify](./zenify): Binary dòng lệnh của ZenifyKit, chứa mọi lệnh workspace và plugin skill đi kèm.
- [zenify npm login](./zenify_npm_login): Đặt NPM_TOKEN từ gh vào shell profile và cấp scope read:packages để npm install được package private.
