## zenify spec contracts

registry contract: repo/collection mỗi spec khai qua _Blast-radius:/_DB:

```
zenify spec contracts [flags]
```

### Options

```
      --collection string   lọc theo collection trong _DB:
  -h, --help                help for contracts
      --json                in JSON thay vì bảng
      --repo string         lọc theo repo trong _Blast-radius:
      --workspace string    thư mục workspace (mặc định cwd)
```
