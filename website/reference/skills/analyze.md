# `/znf:analyze`

Use to inspect a written spec+plan pair BEFORE implementing — mechanically checks requirement coverage (FR→task), leftover clarification markers, and Brief structure, then adds judgment on SC-testability, necessity, and DB-safety. advisory only, never blocks.

## Cách gọi

```text
/znf:analyze
```

## Tool được phép

`Read Grep Bash(zenify analyze *)`

## Nguồn

Sinh bởi `zenify docs gen` từ frontmatter `SKILL.md` trong binary; phần thân skill là agent-read, không hiển thị ở đây.
