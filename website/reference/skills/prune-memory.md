# `/znf:prune-memory [optional: path to a memory dir, defaults to this project's]`

Review and prune auto memory in one batch — remove task logs, dead references, rival memories, and misfiled scopes. Use when the SessionStart reminder fires, or when memory feels noisy or the index is growing.

## Cách gọi

```text
/znf:prune-memory [optional: path to a memory dir, defaults to this project's]
```
