# `/sql-data-safety`

Use when reading or writing SQL through a pooled driver or a thin query client (raw parameterized SQL, not a full ORM mapping) — covers the tenant filter every statement must carry, parameterization against injection, connection-pool and timeout limits, transaction scoping, and schema changes via reviewed migrations.
