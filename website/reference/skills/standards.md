# `/znf:standards`

Use after implementing a plan — checks test-traceability: every FR/SC has a real test on disk, not just a testable-shaped SC. Mechanical command + judgment on whether the test truly asserts the requirement. advisory only, never blocks.

## Cách gọi

```text
/znf:standards
```

## Tool được phép

`Read Bash(zenify standards *)`

## Nguồn

Sinh bởi `zenify docs gen` từ frontmatter `SKILL.md` trong binary; phần thân skill là agent-read, không hiển thị ở đây.
